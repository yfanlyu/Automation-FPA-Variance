# Automated FP&A Variance & Value Driver Analysis

An end-to-end Python-based FP&A analytics project designed to automate financial performance analysis, variance identification, value-driver decomposition, anomaly detection, and management reporting.

## Business Objective

The solution integrates:

- Actual
- Budget
- Rolling Forecast V1/V2/V3
- Actual vs Budget comparisons
- Revenue and cost drivers
- Operational KPIs

The objective is to move from:

Financial variance -> Materiality -> Business driver -> Management insight
